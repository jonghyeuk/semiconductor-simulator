로봇및센서실습 · 반도체장비전공 · CHAPTER 12

시퀀스
블록형 자동 이송

사람이 버튼을 누르던 동작을 블록으로 적어 장비가 스스로 실행하게 합니다. MOVE·PICK·PLACE·WAIT·SENSOR CHECK·IF의 조합입니다.
이 강의 — 시퀀스가 무엇인지, 왜 조건(IF)과 대기(WAIT)가 필요한지 보고 직접 블록을 엮어 자동 실행합니다.
01 · 왜

동작을 글로 적어 두는 것

1
재현성 사람마다 다른 순서가 아니라, 적힌 대로 항상 같게 실행됩니다.
2
무인 운전 한 번 짜두면 사람 없이 반복합니다.
3
수동을 먼저 한 이유 각 블록이 곧 1~11강에서 손으로 하던 그 동작입니다.
연결 — 수동으로 "언제 되고 안 되는지"를 익혔기에, 시퀀스가 멈춰도 어디가 문제인지 압니다.
02 · 블록

여섯 가지 블록

블록하는 일
MOVE지정 스테이션으로 이동(θ)
PICK웨이퍼를 집는다
PLACE웨이퍼를 놓는다
WAIT조건/시간까지 기다린다
SENSOR CHECK신호가 맞는지 확인
IF조건에 따라 분기
WAIT와 IF가 핵심 — 압력이 목표에 닿을 때까지 기다리고, 센서 상태에 따라 다르게 행동해야 진짜 자동화입니다.
03 · 안전

자동이라도 인터록은 그대로

블록도 거부당한다

편 채 회전하는 MOVE, 압력 안 맞는데 여는 블록은 수동과 똑같이 인터록이 막습니다.

그래서 SENSOR CHECK

다음 블록 전에 조건을 확인하면 시퀀스가 안전하게 흐릅니다.

좋은 시퀀스 = 동작 블록 사이에 확인·대기가 적절히 들어간 시퀀스입니다.
개요

왜 시퀀스로 자동화하나

1
재현성 사람마다 다른 순서가 아니라 늘 같게.
2
무인 운전 한 번 짜면 반복.
3
기록 무슨 순서로 했는지 그대로 남습니다.
전제 — 1~11강에서 손으로 익힌 동작이 곧 블록이 됩니다.
01 · 블록 심화 ①

MOVE · PICK · PLACE

M
MOVE 지정 스테이션으로 회전·이동. (수동의 Rotate+Extend에 해당)
P
PICK 집기(Extend·Up·Retract).
Pl
PLACE 놓기(Extend·Down·Retract).
대응 — 각 블록 = 앞서 손으로 한 동작 묶음. 낯설지 않습니다.
02 · 블록 심화 ②

WAIT · SENSOR CHECK · IF

W
WAIT 조건/시간까지 기다림(예: 목표 압력 도달).
S
SENSOR CHECK 신호가 맞는지 확인 후 진행.
IF
IF 조건에 따라 분기(예: 챔버 비었으면 PM1, 아니면 PM2).
핵심 — WAIT·IF·CHECK가 있어야 상황에 대응하는 "진짜" 자동화.
03 · 예시

FOUP→Load Lock 시퀀스 예

#블록
1MOVE FOUP
2PICK slot1
3SENSOR? Presence ON
4MOVE Aligner → PLACE
5WAIT Align done
6PICK → MOVE LL → PLACE
읽는 법 — 위에서 아래로 한 줄씩. 각 줄이 곧 한 동작.
04 · 안전

자동이라도 인터록은 살아있다

블록도 거부된다

편 채 MOVE, 압력 안 맞는 개방 블록은 수동과 똑같이 인터록으로 멈춥니다.

그래서 CHECK

동작 블록 사이에 SENSOR CHECK/WAIT를 넣어 조건을 보장합니다.

좋은 시퀀스 = 동작 사이에 확인·대기가 적절히 낀 시퀀스.
05 · 디버깅

시퀀스가 멈추면

1
멈춘 줄 확인 어느 블록에서 섰는지 본다.
2
로그 확인 그 블록의 알람 코드.
3
조건 보강 앞에 WAIT/CHECK를 추가.
대개 — 멈춤은 "조건이 아직 안 됐는데 다음을 시도"해서입니다.
06 · 흔한 실수

시퀀스 작성 실수

실수결과
WAIT 누락압력 미달 상태로 개방 → 알람
CHECK 없음빈 손으로 Place 진행
Retract 빠짐편 채 MOVE → 충돌
교훈 — 사람이 손으로 지키던 순서를, 블록에서도 그대로 지켜야 합니다.
개념 · 상태

시퀀스는 상태를 따라 흐른다

지금 상태 → 다음 상태

"웨이퍼 집음" → "정렬 완료" → "LL 안착"처럼, 각 블록이 상태를 한 칸 전진시킵니다.

조건이 전이의 열쇠

다음 상태로 가려면 센서 조건이 충족돼야 합니다(SENSOR CHECK).

관점 — 좋은 시퀀스 = 상태와 전이 조건이 분명한 시퀀스.
개념 · 예외

잘못됐을 때의 길도 그려둔다

1
정상 경로 조건 충족 시 다음으로.
2
예외 경로 조건 실패 시 멈춤·알람·복구 블록으로.
실무 — 예외 처리 없는 시퀀스는 작은 이상에도 통째로 멈춥니다.
개념 · 병렬

둘을 동시에 — 듀얼 암 스케줄

겹쳐서 일한다

한 손이 새 웨이퍼를 집는 사이 다른 손이 완료품을 빼내, 시간을 겹칩니다.

효과 — 같은 장비로 처리량↑. 5강 "손이 둘"의 자동화 버전.
개념 · 레시피

시퀀스와 레시피

1
레시피 어떤 공정을 어떤 조건으로 할지의 설정.
2
시퀀스 그 레시피대로 웨이퍼를 옮기고 처리하는 순서.
역할 분담 — 이송 시퀀스는 "웨이퍼를 제때 제자리에" 두는 데 집중합니다.

실습 미션

12강에서 직접 해볼 것

1
블록 6개 이상으로 이송 시퀀스를 구성한다.
2
끝까지 실행해 오류 없이 완주한다.
3
자동으로 Load Lock까지 웨이퍼를 보낸다.
완료 기준 — 자동 실행으로 웨이퍼가 Load Lock에 도착하면 12강 종료.
정리 · 자가 점검

12강에서 남길 것

1
블록 = 동작 수동 동작을 글로 엮은 것.
2
WAIT·IF·SENSOR 조건과 대기가 자동화의 핵심.

Q1

동작 블록 사이에 SENSOR CHECK를 넣는 이유는?
